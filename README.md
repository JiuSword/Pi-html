## 实测数据（不是估算）

本系列报告本身就是一次 pi 真实端到端运行的产物（真实 API key、真实工具执行，运行在第三方宿主 pi-dashboard 中）。报告内的实测章节数据由会话 JSONL（328 条目 / 324 消息）逐条解析得出：

| 指标 | 实测值 |
|---|---|
| 会话墙钟 / LLM 调用 / 工具调用 | 3.94 h / 161 / 153 |
| 缓存命中率 | **99.29%**（新输入仅 0.71%） |
| 上下文 中位 / 峰值 | 130,256 / 246,225 token |
| 总成本 | **$0.359**（约 ¥2.6） |
| 工具批延迟 p50 / p90 | 0.34 s / 4.92 s |
| 工具失败率（均自恢复） | 8.6%（13/151） |

> 边界：N=1 单模型单任务、无并发与对照组，**不是性能基准**。
